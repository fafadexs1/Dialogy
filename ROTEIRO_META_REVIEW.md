# Roteiro de Gravação para Revisão do App (Meta / Facebook)

Este roteiro foi elaborado para atender à solicitação de **"Page Public Metadata Access"** e resolver a rejeição anterior.

> **Objetivo:** Demonstrar claramente que o app acessa e exibe informações públicas (Metadados) das Páginas do Facebook (como Sobre, Localização, Site, Status de Verificação), e não apenas o Nome/ID.

---

## 1. Preparação (Antes de Gravar)

*   **Idioma:** Se possível, mude o idioma da interface do seu navegador ou sistema para **Inglês** (ou garanta que o app em português tenha botões claros). A Meta prefere vídeos em inglês, mas se não for possível, narre ou legende em inglês.
*   **Dados:** Certifique-se de que a conta do Facebook que você vai usar para testar possui acesso a **pelo menos 2 páginas** diferentes.
*   **Conteúdo das Páginas:** Garanta que essas páginas tenham dados preenchidos no Facebook (Endereço, Site, Sobre/Descrição, Foto de Capa/Perfil), para que esses dados apareçam no nosso novo layout.
*   **Limpeza:** Se já houver páginas conectadas, remova-as antes de começar a gravar para mostrar o fluxo do zero.

---

## 2. O Roteiro (Passo a Passo)

### Parte 1: Início e Navegação
1.  Comece a gravação na **Dashboard** (Paínel Inicial) do Dialogy.
2.  Navegue até o menu **Integrações** (Integrations).
3.  Clique no card **Facebook Messenger**.
4.  *Narração Sugerida (ou Legenda):* "Navigating to Facebook Messenger Integration to connect a Page."

    > **Nota:** O processo é idêntico para a **Integração do Instagram**. Se o analista pediu para mostrar ambos, repita os passos abaixo também na tela de **Instagram Business**, onde agora também exibimos os metadados (Sobre, Localização, Site, Seguidores).

### Parte 2: O Fluxo de Login (Meta Login)
5.  Na tela de integração, certifique-se de estar na aba **Automático**.
6.  Clique no botão **Continuar com Facebook** (Login with Facebook).
7.  **Importante:** A janela de popup do Facebook vai abrir. **Não oculte essa janela**. A gravação deve capturar o popup.
8.  No popup, clique em "Continuar como [Seu Nome]".
9.  Selecione as páginas que deseja dar acesso.
10. Confirme as permissões.
11. O popup fechará.

### Parte 3: Demonstração dos Metadados (O Ponto Crítico)
12. Ao fechar o popup, a lista de páginas ("Selecione a Página para conectar") vai carregar.
13. **Esta é a parte mais importante:**
    *   Passe o mouse lentamente sobre as páginas listadas.
    *   Observe que agora exibimos dados ricos: **Descrição (About), Localização (City/Country), Site e Seguidores**.
    *   *Ação:* Destaque esses dados com o mouse.
    *   *Narração Sugerida:* "Here we verify the public metadata of the available pages provided by the user. We display the Page Name, Location, Website, About info, and Verification Status to help the user identify the correct page."
    *   *(Isso justifica o uso da permissão "Page Public Metadata Access" ou equivalente, pois você está mostrando dados públicos da página para identificação).*

### Parte 4: Conexão e Finalização
14. Selecione uma das páginas (clique no Radio Button).
15. Clique no botão **Conectar Página** (Connect Page).
16. Aguarde a mensagem de sucesso ("Conexão Estabelecida").
17. Mostre o card de "Conexões Ativas" atualizado com a página conectada.
18. Encerre a gravação.

---

## 3. Dicas Extras para Aprovação

*   **Não corte o vídeo:** A Meta exige um fluxo contínuo sem edições bruscas no meio do processo de login.
*   **Mostre o URL:** É bom que a barra de endereços do navegador esteja visível mostrando que é o seu domínio verificado.
*   **Resolução:** Grave em alta resolução (1080p) para que os textos de "About/Location" fiquem legíveis.
