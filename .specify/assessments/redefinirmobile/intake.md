# Idea Intake: Redefinição da Experiência Mobile como Chat Nativo

- **Slug**: redefinirmobile
- **Created**: 2026-09-14
- **Source**: pasted text
- **Type**: improvement

## Idea (as captured)

> "Precisamos deixar o modo mobile realmente um modo Mobile como se fosse um chat"

## Restated

A proposta solicita a reformulação integral da interface e do fluxo mobile do Dialogy para que opere como um aplicativo de mensagens nativo para smartphones (estilo WhatsApp, Telegram ou Apple Messages), priorizando ergonomia por toque, navegação fluida em tela cheia e interação direta de chat em vez de uma adaptação responsiva da interface desktop.

## Origin & Context

- **Raised by**: Stakeholder / Usuário do Dialogy
- **Trigger**: Percepção de que a experiência em dispositivos móveis atual necessita de uma dinâmica verdadeiramente pensada para smartphone ("como se fosse um chat"), garantindo maior agilidade no atendimento em trânsito.
